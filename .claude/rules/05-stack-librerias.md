# Stack y librerías (referencia rápida)

Antes de instalar o inventar otra lib, leer:

**`docs/architecture/04-stack-y-librerias.md`**

Ahí están: React, Vite, Tailwind v4, Motion, React Router, `cn()`, **`cssvg-icons`** (iconos UI obligatorios), qué no usamos, y cómo documentar una lib nueva.

Al añadir dependencia: actualizar esa ficha + `docs/changes/`.

**Permiso:** libs/skills de **optimización** (carga, imágenes, LCP) están permitidas si mejoran velocidad real y se documentan.

Iconos UI nuevos → regla `07-icons-cssvg` (no Lucide nuevo).  
Assets → regla `08-assets-optimizacion`.
