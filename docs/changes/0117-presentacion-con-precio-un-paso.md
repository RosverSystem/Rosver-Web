# Cambio: Tipo + cantidad + precio en un solo paso

**Fecha:** 2026-09-08  
**Tipo:** fix | ux  
**Versión:** 0.1.25

## Qué cambió

- Fase 3 productos y Listado de precios: un solo formulario **tipo → cantidad → precio venta** (+ mayorista opcional).
- Ya no hay que crear presentación y luego «Usar para precio» aparte.

- [ ] Producto wizard fase 3: Agregar con tipo, cantidad y precio
